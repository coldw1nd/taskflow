# Карта эндпоинтов TaskFlow

Все защищённые запросы передают `Authorization: Bearer <JWT>`. Формат данных — JSON; коллекция задач возвращает объект пагинации. URL используют существительные, действие определяется HTTP-методом.

| Метод | Путь | Назначение | Доступ | Успешный ответ |
|---|---|---|---|---|
| GET | `/api/health` | Проверка приложения и БД | Публичный | 200 |
| POST | `/api/auth/register` | Регистрация пользователя | Публичный | 201 |
| POST | `/api/auth/login` | Вход и получение JWT | Публичный | 200 |
| GET | `/api/auth/me` | Профиль текущего пользователя | JWT | 200 |
| GET | `/api/tasks` | Список задач; `status`, `tag_id`, `page`, `limit` | JWT | 200 |
| POST | `/api/tasks` | Создание задачи | JWT | 201 |
| GET | `/api/tasks/{id}` | Получение одной задачи | JWT, владелец | 200 |
| PATCH | `/api/tasks/{id}` | Частичное обновление задачи | JWT, владелец | 200 |
| PUT | `/api/tasks/{id}/tags` | Полная замена набора тегов задачи | JWT, владелец | 200 |
| DELETE | `/api/tasks/{id}` | Удаление задачи | JWT, владелец | 204 |
| GET | `/api/tags` | Список тегов пользователя | JWT | 200 |
| POST | `/api/tags` | Создание тега | JWT | 201 |
| DELETE | `/api/tags/{id}` | Удаление тега | JWT, владелец | 204 |

## Семантика методов

- `GET` не изменяет ресурс и может повторяться.
- `POST` создаёт новый ресурс и не является идемпотентным.
- `PUT /api/tasks/{id}/tags` полностью заменяет набор тегов; повтор того же набора приводит к тому же результату.
- `PATCH` изменяет переданные поля задачи.
- `DELETE` удаляет ресурс; повторный запрос после удаления вернёт 404.

## Статусы ошибок

| Код | Значение | Когда используется |
|---|---|---|
| 400 | Bad Request | Ошибка валидации или некорректный ID/параметр |
| 401 | Unauthorized | Отсутствующий, неверный или просроченный JWT |
| 404 | Not Found | Объект отсутствует или не принадлежит пользователю |
| 409 | Conflict | Повтор email или имя тега |
| 429 | Too Many Requests | Превышен лимит запросов |
| 503 | Service Unavailable | SQLite временно заблокирована |
| 500 | Internal Server Error | Непредвиденная серверная ошибка; внутренние подробности не раскрываются |

## Формат ошибки

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Validation failed",
    "details": [
      { "path": "title", "message": "Required" }
    ]
  }
}
```

Полная спецификация хранится в `openapi.yaml`; HTML-страница `/api/docs` загружает её в Swagger UI. Спецификация является отдельным контрактным файлом и должна обновляться вместе с изменением маршрутов.
