# TaskFlow

TaskFlow — учебное веб-приложение для управления личными задачами.

## Возможности

- Регистрация пользователя по email и паролю.
- Вход в систему с выдачей JWT-токена.
- Создание задач.
- Просмотр списка задач.
- Отметка задачи выполненной.
- Возврат задачи в активный статус.
- Удаление задачи.
- Дедлайны задач.
- Подсветка просроченных задач.
- Теги для задач.
- Привязка тегов к задачам.
- Удаление тегов.
- Фильтрация задач по статусу.
- Серверная валидация данных.
- Изоляция данных между пользователями.
- Интеграционные тесты.
- Линтер.
- Конвейер GitHub Actions.

## Стек

- Node.js 22 LTS
- Express
- SQLite (better-sqlite3)
- JWT
- Zod
- Jest
- Supertest
- ESLint
- GitHub Actions

## Установка

```bash
npm install
```

Создать файл окружения.

Для Windows:

```bash
copy .env.example .env
```

Для Linux и macOS:

```bash
cp .env.example .env
```

В файле `.env` задаются:

```text
PORT
JWT_SECRET
DB_FILE
```

## Запуск

```bash
npm start
```

Приложение будет доступно по адресу:

```text
http://localhost:3000
```

## Основные команды

Запуск сервера:

```bash
npm start
```

Запуск сервера с автоматической перезагрузкой:

```bash
npm run dev
```

Запуск тестов:

```bash
npm test
```

Запуск линтера:

```bash
npm run lint
```
