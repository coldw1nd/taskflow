# TaskFlow

TaskFlow — учебное монолитное веб-приложение для ведения личных задач. Серверная часть работает на Node.js и Express, данные хранятся в SQLite.

## Состав реализации

- регистрация и вход по email/паролю с bcrypt-хешированием и JWT;
- CRUD собственных задач, статусы `active` и `completed`, сроки выполнения;
- пользовательские теги и связь задач с тегами M:N;
- фильтрация, пагинация и проверка принадлежности объектов пользователю;
- валидация входных данных, параметризованные SQL-запросы, Helmet, CORS и rate limit;
- сервисный слой, транзакции и журнал действий `audit_logs`;
- последовательные SQL-миграции и скрипты отката;
- OpenAPI 3.0 и Swagger UI;
- интеграционные и database tests, ESLint и GitHub Actions CI;
- проверка здоровья API и SQLite.

## Требования

- Node.js 22 или совместимая актуальная LTS-версия;
- npm;
- SQLite через пакет `better-sqlite3` (отдельный сервер СУБД не требуется).

## Локальный запуск (Windows PowerShell)

```powershell
npm install
Copy-Item .env.example .env
npm run migrate
npm run dev
```

Откройте `http://localhost:3000/`. Проверка API: `http://localhost:3000/api/health`. Swagger UI: `http://localhost:3000/api/docs`. OpenAPI: `http://localhost:3000/openapi.yaml`.

## Основные команды проверки

```bash
npm run lint
npm test
npm run db:check
```

Для дополнительного замера производительности запустите сервер и во втором терминале выполните `npm run perf`. Скрипт создаёт тестового пользователя и задачи в БД того экземпляра API, к которому подключается. Используйте отдельную временную БД, а не основную.

## Миграции и осторожность

Миграции применяются по порядку командой `npm run migrate` или при инициализации приложения. Перед экспериментами с откатом сохраните копию файла SQLite вручную. Откат `001_core.sql` удаляет основные таблицы и данные; он требует явного `CONFIRM_DESTRUCTIVE_ROLLBACK=yes` и не нужен для обычного запуска.
